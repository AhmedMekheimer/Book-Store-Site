# 📚 PolyBook Store - ASP.NET Core MVC Book Store Application

A fully-featured book store built with ASP.NET Core MVC, featuring customer and admin areas, identity management, and comprehensive CRUD operations.

![SQL Server](https://img.shields.io/badge/Database-SQL_Server-red?logo=microsoft-sql-server)
![Entity Framework](https://img.shields.io/badge/ORM-Entity_Framework-green)
![Bootstrap](https://img.shields.io/badge/UI-Bootstrap_5-blue?logo=bootstrap)

## 🌟 Key Features

### 👥 Customer Area
- **Books Home & Details Pages** - Browse and view detailed information about books
- **Authors Home & Details Pages** - Explore authors and their works

### 🔐 Identity Management
- **User Registration & Login** - Complete user account management
- **Email Confirmation** - Secure account verification system
- **OTP-based Password Recovery** - One-time password for secure password reset
- **User Profile Editing** - Personal information management

### ⚙️ Admin Area
- **Complete CRUD Operations** for:
  - Books management
  - Authors management
  - Publishers management
  - Categories management
  - Users administration
- **Media Uploads** - Support for images and videos
- **Server-Side Validations** - Robust data validation

### 🛠️ Technical Implementation
- **DbContext** with Entity Framework Core
- **Identity User & Role Management**
- **Email Sender Service**
- **Repository Pattern** following SOLID principles
- **Authentication & Authorization**
